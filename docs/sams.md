# Using maxodiff in SAMS

!!! info "Work in progress"
The integration of maxodiff in
[SAMS](https://www.genecascade.org/sams-cgi/index.cgi) (Symptom annotation
made simple) is under development. This page will be completed when it is
released.

SAMS is a database and phenotyping tool for precision medicine. It supports
documenting a patient's clinical signs and symptoms with
[HPO](https://hpo.jax.org/) terms and can export them as a
[phenopacket](background.md#ga4gh-phenopackets). The planned integration will
let you send a patient from SAMS to maxodiff and see which diagnostic
procedures are expected to help most.
